<h1 align="center">Easy Shopping</h1>
<br>
<p align="lefth">
  O Easy Shopping é um exercicio da <a href="https://www.devclub.com.br">DevClub</a> onde o intuito é trabalhar
  a responsividade do site easy, deixando-o adaptavél a telas menores. A imagem foi trabalhada usando a posição relativa,
  mostrando assim outros medotos de posições que se pode fazer, além de toda a estilização do site.
</p>
<br>
<h2>Tecnologias utilizadas</h2>
- HTML
- CSS
